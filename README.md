# Edward Tanaka Magejo — Personal Engineering Portfolio

A bespoke, high-performance editorial developer portfolio showcasing selected systems engineering, full-stack architecture, and interactive web craft.

## Highlights
- **Cinematic Video Hero**: Seamless deceleration loop, zero layout shift, and organic texture junction.
- **Standalone Monogram Navigation**: Ultra-clean, borderless typography branding.
- **Interactive 3D Sovereign Coin**: Procedural Three.js 3D model with drag-distance discrimination and tactile physics.
- **Editorial Runway Exhibition**: Zero-seam ballooning stage with fluid card navigation.
- **Mobile-First & Cross-Platform**: Fully optimized for iOS Safari (WebKit playsinline, 100dvh safe-area) and Android.

## Tech Stack
- HTML5 / CSS3 (CSS Variables, Flexbox, Grid, Subgrid)
- JavaScript (ESNext)
- [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform) & ScrollTrigger
- [Three.js](https://threejs.org/) (WebGL 3D Rendering)

## Running Locally
To run the portfolio locally, serve the directory with any standard static HTTP server:

```bash
# Using Python
python -m http.server 8080

# Using Node / npx
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
