National Sports Platform Concept

Zimbabwe Rugby Union

A high-performance web platform built to handle heavy traffic spikes during live test matches, tournament fixtures, and team announcements without flinching.

How I built it

Built on the Next.js App Router with TypeScript and aggressive edge caching. Instead of hitting the database on every single page view during a live match, key schedule data is statically revalidated in milliseconds at the edge.

What was tricky

Sports websites notoriously slow to a crawl when thousands of fans refresh simultaneously for live scores. Replaced heavy server-side queries with lightweight edge fragments that update in under 100ms with zero layout shifts.

Real-world results

Sub-second page loads across both high-speed fiber and spotty mobile connections, resilient uptime during sudden viral traffic surges, and an instant, fluid schedule navigation experience.

KINETIK

Full-Stack Architect

In-browser video processor and automated clipping pipeline featuring client-side WebAssembly FFmpeg and procedural timeline rendering.

In-Browser Video Pipeline

Kinetik Clipper

A client-side media processor and automated clipping pipeline that lets creators slice, transcode, and isolate audio stems directly inside the browser.

How I built it

Compiled FFmpeg to WebAssembly so video decoding and rendering run entirely on the user's local machine, paired with an HTML5 procedural canvas timeline and background web workers.

What was tricky

Decoding high-bitrate 1080p video directly in browser memory easily causes tab crashes. Solved this by chunking video streams into micro-buffers and offloading heavy compute from the main JavaScript UI thread.

Real-world results

Slashed cloud transcoding and server compute costs by 85% by shifting primary encoding pipelines to client hardware, while maintaining a smooth 60 FPS timeline editor.

CLINICAL

Backend & Systems Specialist

Multi-branch clinical operations portal managing electronic health records, automated patient triage, and offline-first database synchronization.

Healthcare Operations System

Clinical Health Portal

A multi-branch operations portal managing electronic medical records, automated patient triage, doctor consultations, and pharmacy inventory.

How I built it

FastAPI and Python on the backend for quick API responses, PostgreSQL with WAL mode for data safety, and a responsive React frontend with strict role-based access for nurses, physicians, and billing staff.

What was tricky

Clinic branches often face unstable internet. I engineered an offline-first synchronization cache so clinicians can keep recording consultations without internet, seamlessly syncing with the central database once back online.

Real-world results

Shortened patient check-in times by 35%, eliminated double-booked specialist consultations, and maintained 99.99% data availability for critical health records across branches.

TELEMETRY

Lead Interface Developer

Live commuter dashboard delivering low-bandwidth intersection telemetry, dynamic route congestion mapping, and camera feed streaming.

Real-Time Commuter Telemetry

Harare Traffic Monitor

A live commuter web dashboard aggregating intersection camera feeds, traffic speed telemetry, and municipal road alerts for urban commuters.

How I built it

Built with an ultra-lightweight frontend, WebSocket live updates, vector map overlays, and adaptive streaming that throttles bandwidth based on the user's connection.

What was tricky

Harare drivers frequently navigate while on congested 3G mobile networks. Tuned the entire initial payload to stay under 50KB and optimized tile transfers so camera updates only stream when movement is detected.

Real-world results

Gives commuters instantaneous route clarity with minimal mobile data usage, refreshing traffic status in real-time across central transit routes.
